## 📖 Descripción del Proyecto

El proyecto consiste en el desarrollo de distintos ejercicios utilizando HTML, CSS y JavaScript.

El objetivo es aplicar conceptos fundamentales de programación visual y desarrollo web, incluyendo manipulación del DOM, eventos y módulos de JavaScript.

---

## 🧱 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## ⚙️ Contenido del trabajo práctico

Durante el desarrollo del TP se trabajó con:

- Estructura de páginas HTML
- Uso de funciones flecha
- Template strings
- Manipulación del DOM
- Eventos en JavaScript
- Módulos (`export` e `import`)
- Estilos básicos con CSS
- Interacción dinámica con el usuario
